# Maxim Degtiarev — Developer Portfolio

A bilingual (EN/ES) portfolio presenting Maxim's programming work to clients and employers. Only software work is presented; personal/non-programming activities are out of scope.

## Language

**Years of Experience**:
Time since Maxim started professional freelance development in July 2022. Shown as a floor ("4+"), never rounded up.
_Avoid_: Years programming (studies since 2010 don't count)

**Project**:
A piece of shipped software shown as a card in the Portfolio section, with stack, a short impact description and, when public, a live link.
_Avoid_: Work, Job

**Ongoing Project**:
A Project still under active development for a client; shown with an "In progress" badge and no live link until launch.

**Client Project**:
A Project built for someone else. Its subject matter (e.g. a dance federation) describes the client, not Maxim's personal interests.

**Personal Project**:
A Project built for learning or practice, with no real client (e.g. Natourex). Always badged as such; never described as "enterprise" or client work.

**Impact Metric**:
A number claimed on a Project card (e.g. "+80% confirmations"). Must match Maxim's resume or be verifiable; otherwise omitted.

## Example dialogue

> **Client:** "How long have you been doing this?"
> **Maxim:** "4+ years — I've been freelancing full-stack since July 2022."
